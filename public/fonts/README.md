# Self-hosted fonts

These files are self-hosted to avoid third-party runtime requests:

- Manrope (Latin variable font, weights 400–800)
- DM Mono (Latin, weights 400 and 500)

They were obtained from Google Fonts and are distributed under the SIL Open Font License 1.1. See `OFL-Manrope.txt` and `OFL-DM-Mono.txt`.
